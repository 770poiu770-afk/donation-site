# אתר תרומות עם PayPal — מדריך הפעלה ועלייה לאוויר

אתר תרומות מלא: עמוד בית בעברית ובאנגלית, תרומה מהירה ואנונימית (בחירת סכום ותשלום, בלי הרשמה ובלי טופס פרטים), תשלום דרך PayPal או בכרטיס אשראי בלי חשבון PayPal, תרומה חודשית, ומערכת ניהול מלאה.

---

## מה יש במערכת

**לתורם**
- אפשרויות התרומה מופיעות מיד בראש העמוד.
- 13 סכומים מוכנים ($5 עד $100,000) ושדה לסכום חופשי עד $1,000,000.
- חד-פעמית או חודשית בלחיצה אחת.
- כפתורי PayPal ו"כרטיס חיוב או אשראי" מופיעים מיד, בלי שלבי ביניים. הכפתור פותח ישירות את דף התשלום המאובטח של PayPal.
- לא נדרשים שם, טלפון, כתובת או הרשמה. שם, אימייל והקדשה הם רשות בלבד, מקופלים כברירת מחדל.
- שמות תורמים לא מוצגים באתר אף פעם.
- עמוד תודה עם מספר העסקה, עמודי שאלות ותשובות, צור קשר, מדיניות פרטיות ותנאי שימוש.
- מותאם לאייפון, לאנדרואיד ולמחשב, בעברית (RTL) ובאנגלית.

**לך (מערכת ניהול בכתובת ‎/admin)**
- כל התרומות: שם (כפי ש-PayPal מעבירה), סכום, תאריך ושעה, מספר עסקה ב-PayPal, סטטוס, עמלה ונטו.
- סך הכול, היום, השבוע, החודש, גרף של 30 יום, וסיכומים יומיים, שבועיים וחודשיים.
- חיפוש וסינון לפי טקסט, סטטוס, סוג, תאריכים וסכום, וייצוא ל-Excel (CSV).
- הוראות קבע, פניות מטופס יצירת הקשר, ומסך מצב החיבור ל-PayPal.
- יומן מלא לכל עסקה.

**אבטחה**
- PayPal Orders API v2 ו-Subscriptions API. כל תשלום נוצר ומאומת בצד השרת. הדפדפן לא קובע אם תשלום הצליח.
- אימות סכומים בצד השרת ($1 עד $1,000,000). הסכום שנגבה בפועל מושווה לסכום שנשמר, ואי-התאמה מסומנת "לבדיקה".
- Webhooks עם אימות חתימה מול PayPal. Webhook מזויף נדחה.
- הגנה מעסקאות כפולות: מפתח `PayPal-Request-Id` בכל פעולה, אינדקסים ייחודיים, והתעלמות מ-Webhook שהגיע פעמיים.
- טיפול בתשלום שנדחה (התורם יכול לנסות אמצעי אחר), בתשלום שבוטל, בתשלום ממתין, בהחזר מלא או חלקי ובחיוב חוזר (Chargeback).
- פרטי כרטיס אשראי לא מגיעים לשרת שלך בכלל.
- מפתחות רק במשתני סביבה (`.env`), אף פעם לא בקוד.
- כניסת מנהל עם סיסמה מוצפנת (bcrypt), הגבלת ניסיונות, הגנת CSRF, כותרות אבטחה (CSP, HSTS) והגבלת קצב בקשות.

## הפעלה מהירה במחשב (מצב הדגמה, בלי PayPal אמיתי)

1. התקינו את [Node.js](https://nodejs.org) גרסה 20 ומעלה.
2. פתחו טרמינל בתיקיית הפרויקט והריצו:
   ```
   npm install
   npm run demo
   ```
3. היכנסו לכתובת http://localhost:3000 ונסו לתרום. נפתח חלון PayPal מדומה.
4. מערכת הניהול: http://localhost:3000/admin, משתמש `admin`, סיסמה `demo-password-123`.

## מה צריך ממך כדי לעלות לאוויר

### 1. חשבון PayPal Business
- נדרש חשבון **PayPal Business** מאומת על שם העמותה. מנויים חודשיים ותשלום בכרטיס בלי חשבון זמינים רק בחשבון עסקי.
- תשלום בכרטיס בלי חשבון PayPal (Guest Checkout) זמין ברוב המדינות, בכפוף להחלטת PayPal לגבי החשבון והמדינה של התורם.
- ל-PayPal יש מגבלת סכום לעסקה בודדת, בדרך כלל עשרות אלפי דולרים, בהתאם לחשבון. סכומים גבוהים מהמגבלה יידחו על ידי PayPal ולא על ידי האתר. אפשר לבקש מ-PayPal להעלות את המגבלה.

### 2. מפתחות API
1. היכנסו ל-https://developer.paypal.com עם חשבון ה-Business.
2. **Apps & Credentials** ← בחרו **Sandbox** ← **Create App**.
3. העתיקו את **Client ID** ואת **Secret**.
4. אחרי שהבדיקות עוברים, חזרו על אותו תהליך במצב **Live**.

### 3. שרת ודומיין
צריך שרת Node.js עם כתובת **https**, למשל `donate.your-org.org`. אפשרויות:
- **Render / Railway / Fly.io**: מעלים את התיקייה, מגדירים משתני סביבה ודיסק קבוע (Persistent Disk) לתיקייה `data`.
- **שרת VPS** עם Docker: `docker compose up -d --build`, ומאחוריו Nginx או Caddy עם תעודת SSL.

> חשוב: מסד הנתונים הוא קובץ בתיקייה `data/`. ודאו שהיא נשמרת בדיסק קבוע ושיש גיבוי (`npm run backup`).

### 4. הגדרת קובץ ‎`.env`
העתיקו את `.env.example` ל-`.env` ומלאו:

```
NODE_ENV=production
BASE_URL=https://donate.your-org.org
PAYPAL_MODE=sandbox
PAYPAL_CLIENT_ID=...        ← מ-PayPal
PAYPAL_CLIENT_SECRET=...    ← מ-PayPal
```

צרו סיסמת מנהל (לפחות 12 תווים):
```
npm run admin:password
```
העתיקו את שתי השורות שיודפסו (`ADMIN_PASSWORD_HASH` ו-`SESSION_SECRET`) לתוך `.env`.

### 5. רישום Webhook
אחרי שהאתר עולה בכתובת https:
```
npm run paypal:webhook
```
הפקודה רושמת את הכתובת `https://.../webhooks/paypal` ב-PayPal ומדפיסה `PAYPAL_WEBHOOK_ID=...`. הוסיפו את השורה ל-`.env` והפעילו את השרת מחדש.
(אפשר גם ידנית: ב-developer.paypal.com ← האפליקציה ← Add Webhook ← הכתובת ← All events.)

### 6. בדיקה ב-Sandbox
```
npm run check
```
הפקודה בודקת שההגדרות תקינות ושה-PayPal מקבל את המפתחות. אחר כך:
- בצעו תרומה חד-פעמית עם חשבון בדיקה מ-developer.paypal.com ← Sandbox accounts.
- בצעו תרומה בכרטיס בדיקה ("Debit or Credit Card"). כרטיסי בדיקה זמינים ב-developer.paypal.com ← Card testing.
- בצעו תרומה חודשית.
- בדקו ב-/admin שהתרומות מופיעות, ושבמסך "מערכת ו-PayPal" מגיעים Webhooks.

### 7. מעבר ל-Live (הפעולה האחרונה)
ב-`.env` שנו:
```
PAYPAL_MODE=live
PAYPAL_CLIENT_ID=...       ← מפתחות ה-Live
PAYPAL_CLIENT_SECRET=...
```
הריצו שוב `npm run paypal:webhook` (Webhook נפרד ל-Live), עדכנו את `PAYPAL_WEBHOOK_ID`, הפעילו מחדש, ובצעו תרומה אמיתית קטנה ($1) לבדיקה. אפשר להחזיר אותה מתוך PayPal, וההחזר יופיע אוטומטית במערכת הניהול.

## התאמת תוכן

כל הטקסטים באתר נמצאים בקובץ אחד: **`config/site.json`** (עברית ואנגלית).
**לפני העלייה לאוויר חובה להחליף:**
- שם העמותה (`org.name`), השם הרשמי ומספר העמותה.
- אימייל, טלפון, וואטסאפ וכתובת.
- הכותרות, תיאור המטרה, התוכניות ושאלות ותשובות.
- "מה התרומה שלך יכולה לעשות" (`impactExamples`): כתבו רק דברים נכונים לעמותה שלכם.
- "לאן הולך הכסף" (`funds`): אחוזים יוצגו רק אם תמלאו `percent` במספרים אמיתיים.
- הלוגו: החליפו את `public/img/logo.svg` ואת `favicon.svg` בלוגו שלכם.
- תמונת השיתוף ברשתות: `public/img/og.png` (בגודל 1200×630).

מדיניות הפרטיות ותנאי השימוש (`views/legal.ejs`) הם טיוטה סבירה, אבל **מומלץ שעורך דין יעבור עליהם**.

נתוני "נתרמו עד כה" מוצגים בעמוד הבית אוטומטית מהמסד, רק אחרי 10 תרומות (אפשר לשנות עם `"statsMinDonations"` ב-`site.json`).
